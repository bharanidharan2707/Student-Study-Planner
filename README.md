# Student Study Planner

## About
A study planning website that helps students organize study tasks, set deadlines, and track their progress.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Features
- Add study tasks
- Set task deadlines
- Mark tasks as completed
- Filter pending and completed tasks
- Display study progress
- Save tasks in the browser

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` in a browser, or use Live Server.
3. Add study tasks and track your progress.

## Learning Outcomes
Learn form handling, date inputs, DOM manipulation, filtering, and Local Storage.
